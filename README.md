Baqir Ali — Deployment Guide
Baqir Ali is a multi-tenant AI accounting & finance platform for CPA / CFO / Tax / Audit practices serving clients across Construction, Real Estate, Retail, SaaS, AI and Manufacturing in the USA, UK and EU.

This guide walks you through deploying the app, wiring real OAuth for Gmail / QuickBooks / Xero / Sage / Stripe / Plaid / Shopify / AWS / SAP FICO / Oracle NetSuite, and going live with your first real client.

What's included (13 modules)
Dashboard — live KPIs, cash flow chart, expense breakdown
AI Agents — CEO / CFO / Accountant / Tax (industry-aware, grounded in live ledger)
Clients — multi-client book of business (Construction, Real Estate, Retail, SaaS, AI, Manufacturing)
Transactions — unified ledger across all sources
Journal Entries — Dr/Cr double-entry with balance validation
Invoices — customer & vendor invoices with 6 industry templates (AIA, POS, SaaS subscription, rent, PO, AI services) — one-click PDF download
Import Files — drag-drop PDF / Excel / CSV / XML → auto-extract transactions → post to GL → Trial Balance / P&L / Balance Sheet / Cash Flow / Equity / VAT update instantly
Automations — recurring tasks (daily cash report, Gmail invoice triage, VAT reminder, etc.)
Integrations — connect Gmail, QuickBooks, Xero, Sage, Stripe, Plaid, Shopify, AWS, Zapier, Slack
API & Webhooks — REST API docs + webhook subscriptions for QuickBooks / Xero / SAP FICO / Oracle NetSuite / Zoho Books connections
Tax Center — filings tracker + jurisdiction-aware calculator (USA / UK / Germany / France / Ireland)
Reports — P&L, Balance Sheet, Cash Flow, Trial Balance, Equity, VAT/GST in IFRS / US GAAP / UK FRS 102 / German HGB / French PCG / Irish FRS 102 — PDF / Excel / CSV download
How to Use — plain-English getting started + 3-tier pricing (Free / Pro / Enterprise)
